# Loup-Garou multijoueur (Python)

Version Python : serveur Flask + Flask-SocketIO, interface dans le navigateur.

    pip install -r requirements.txt
    python app.py

Ouvre http://localhost:3000, crée une partie et envoie le lien /salle/CODE à tes amis (5 à 12 joueurs).
Tests du moteur : python test_game.py
